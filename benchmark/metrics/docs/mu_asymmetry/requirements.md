# Requirements — Sensorimotor Mu Asymmetry (`mu_asymmetry`)

Stage 1 of 5 (REQUIREMENTS). This document drives the implementation of the metric plug-in
`benchmark/metrics/m_mu_asymmetry.py`. It is a **spatial analog of the reference FAA metric**
(`m_faa.py`): the same asymmetry machinery and reference frame, relocated from mid-frontal
alpha (F3/F4) to central sensorimotor mu (C3/C4). No shared framework file is modified.

- **key:** `mu_asymmetry`
- **name:** Sensorimotor mu asymmetry
- **submetrics:** `mu_asym`, `mu_c3`, `mu_c4`
- **drop_channels:** `["C3", "C4", "C1", "C2"]`
- **reference frame:** CSD (surface Laplacian, reference-free) — `C.csd` then `C.mean_psd`
- **band:** mu / alpha band, **8–13 Hz**

---

## 1. Scientific motivation — what the metric means

The **mu rhythm** (a.k.a. sensorimotor rhythm / Rolandic mu) is an 8–13 Hz oscillation generated by
primary somatosensory and motor cortex and recorded maximally over the central electrodes **C3
(left hemisphere)** and **C4 (right hemisphere)**, above the hand-knob region. It is the
sensorimotor system's *idling* rhythm — the motor-cortical counterpart of occipital alpha. When the
underlying cortex is at rest, mu power is high; when the cortex engages (actual movement, movement
preparation, motor imagery, or **observation** of another's action — the "mirror" response), mu power
drops via event-related desynchronization (ERD). Mu therefore indexes the momentary engagement /
disengagement of sensorimotor cortex, and — because power varies inversely with cortical activation —
**more mu power means less local activation.**

**Mu asymmetry** applies the Allen-style frontal-alpha-asymmetry (FAA) construction to the central
row: a log ratio of right-hemisphere (C4) to left-hemisphere (C3) mu power. It indexes **hemispheric
lateralization of sensorimotor idling**. Resting sensorimotor lateralization has been examined in
relation to handedness and motor dominance, and mu suppression (the dynamic, task-evoked cousin of
this resting measure) is studied as a putative mirror-system marker in autism, ADHD, and motor
rehabilitation / brain-computer-interface work.

**Interpretive caveat (state prominently in downstream docs):** unlike FAA, resting *mu* asymmetry is
**not** an established trait biomarker. Its clinical literature centers on the dynamic ERD response,
not the resting log-ratio. In this harness `mu_asym` is therefore treated primarily as a
**sensorimotor spatial analog of FAA for testing reconstruction preservation** — not as a validated
psychophysiological trait index. Sign/interpretation should be reported with the inverse-power caveat,
never asserted as a clinical readout.

## 2. Exact definition & frequency band

Band: **mu = 8–13 Hz** (identical numeric band to alpha; `lo=8`, `hi=13`, half-open `[8, 13)` as
`C.bandpower` integrates). Power is Welch PSD, trapezoid-integrated over the band, on CSD data,
averaged over epochs (`C.mean_psd(C.csd(...))`).

Let `pc` be the epoch-mean CSD PSD, `pc[C3]` / `pc[C4]` the rows for those channels, and `f` the
frequency vector. Define:

```
mu_asym = C.log_asymmetry(pc[C4], pc[C3], f, 8, 13)
        = ln( bandpower_8-13(C4) ) - ln( bandpower_8-13(C3) )      # right minus left

mu_c3   = ln( bandpower_8-13(C3) + eps )                            # left-hemisphere mu, log power
mu_c4   = ln( bandpower_8-13(C4) + eps )                            # right-hemisphere mu, log power
```

- **Sign convention** (mirrors FAA `ln(R) - ln(L)`): `mu_asym > 0` ⇒ greater right-central mu ⇒
  *less* right-sensorimotor activation relative to left; `mu_asym < 0` ⇒ the reverse. Report the
  convention explicitly and the inverse-power caveat alongside any value.
- `mu_asym` is a **difference of two log powers**, so any global multiplicative scaling of the data
  (and the CSD normalization constant) **cancels exactly**. `mu_c3` / `mu_c4` are **absolute** log
  powers and do **not** cancel a global scale — this asymmetry-vs-single-channel distinction is
  central to §6.
- `eps` is a small additive floor to keep the logarithm finite (§7). Use the same `1e-20` that
  `C.log_asymmetry` already applies internally, so all three submetrics share one convention.
- Compute exactly via the shared helpers — do not re-implement Welch/CSD/band integration.
  Follow the `m_faa.py` pattern: `f, pc = C.mean_psd(C.csd(data, ch_names))`, then
  `u = C.up(ch_names)` and index with `u.index('C3')` / `u.index('C4')`.

## 3. Electrodes and the drop set that tests it

**Electrodes used:** **C3** (left central) and **C4** (right central) — directly over left- and
right-hemisphere sensorimotor hand cortex. These are the only two sites read by `compute`.

**Drop set (channels removed before reconstruction):** **`["C3", "C4", "C1", "C2"]`.**

Rationale — the drop set must make preservation a genuine test, not a trivial interpolation:

- **C3, C4** are the recording sites themselves; removing them is the definition of the preservation
  test (the reconstruction must re-create the very channels the metric reads).
- **C1, C2** are the immediate medial in-row neighbors (~2–3 cm from C3/C4, between them and Cz). If
  they survived, a reconstruction could recover C3/C4 by near-trivial same-row interpolation from an
  adjacent electrode, and the test would measure interpolation of a neighbor rather than inference of
  the sensorimotor region. Dropping the whole central-hand cluster forces the method to infer mu from
  more distant surviving channels (the FC/CP rows, Cz, T7/T8), which is the hard, informative case.

This mirrors FAA's own logic (FAA drops `F3, F4, F7, F8` — its recording sites plus lateral
partners). Note that **CSD at a surviving central site draws on its ring of neighbors**; because the
truth is recomputed on the full surviving-average-reference montage and compared to the reconstruction
(see `run.py`), the drop set governs what reconstruction must fabricate, not what the Laplacian may
use on the truth pass.

## 4. Submetric outputs and units

| submetric | meaning | units |
|-----------|---------|-------|
| `mu_asym` | right−left log mu asymmetry, `ln(bp C4) − ln(bp C3)` | **dimensionless** log ratio (nepers); scale-invariant |
| `mu_c3`   | left-hemisphere (C3) log mu band power on CSD | **natural log of CSD band power** |
| `mu_c4`   | right-hemisphere (C4) log mu band power on CSD | **natural log of CSD band power** |

Notes on units:

- `mu_asym` is a pure log ratio → dimensionless (natural-log / neper units), independent of the CSD
  normalization and of any global amplitude scaling.
- `mu_c3` / `mu_c4` are `ln` of a band-integrated CSD power. The CSD (surface Laplacian) has units of
  amplitude per area (MNE returns V/m² given the µV→V input scaling in `C.csd`), so the integrated
  band power is in (V/m²)²; its logarithm carries an **arbitrary additive offset** set by the CSD
  normalization. Treat `mu_c3` / `mu_c4` as **relative** quantities to be compared across
  recordings / reconstruction methods, not as absolute physiological powers.
- All three are returned as **finite Python `float`s** (cast numpy scalars with `float(...)`), or
  `float('nan')` when not computable (§7).

Report **all three** together: `mu_asym` for the lateralization construct, `mu_c3` / `mu_c4` as the
single-channel powers that let a reader see whether an asymmetry change came from the left channel,
the right channel, or a common-mode scale shift.

## 5. Reference frame — CSD, and why

**Use CSD (surface Laplacian), reference-free — identical to `m_faa.py`** (`C.csd` then
`C.mean_psd`). Do **not** compute on the scalp average-reference potential.

1. **Reference independence.** An asymmetry taken on average-reference (or any montage-referenced)
   potential is contaminated by the reference choice; a shared reference term can inject a spurious
   left/right imbalance. The surface Laplacian is reference-free, so `mu_asym` reflects the local
   generators rather than the montage.
2. **Spatial sharpening / de-smearing.** Volume conduction spreads distant sources across the scalp;
   in particular **posterior alpha (8–13 Hz) volume-conducts forward to central sites** and overlaps
   the mu band exactly. The Laplacian is a high-pass spatial filter that attenuates broad, distant
   sources and emphasizes focal cortex under C3/C4, so the 8–13 Hz power there better reflects true
   **sensorimotor mu** rather than spread occipital alpha. This separation matters more for mu than
   for frontal alpha, making CSD the right choice here.
3. **Comparability with FAA.** Using the identical pipeline (`C.csd` → `C.mean_psd` →
   `C.log_asymmetry`) makes mu asymmetry directly comparable to the validated FAA reference and keeps
   the plug-in a faithful spatial analog.

## 6. Expected test-retest reliability & the floor it is judged against

**How the floor works** (`run.py` + `aggregate.py`): for each `(metric, submetric)` the harness
computes a **same-day test-retest floor** = mean over subject-days of `|value(Rest1) − value(Rest2)|`
on the full-montage truth recordings. A reconstruction method **preserves** the submetric when its
mean `|recon − truth|` is **below** that floor (it perturbs the metric less than a re-recording does);
otherwise `aggregate.py` marks it `OVER`. The floor is computed empirically from the data — this
document states the *expectation*, not a hard-coded number.

**Expectations:**

- **`mu_c3`, `mu_c4` (single-channel band powers):** resting mu/alpha band power is **reasonably
  reliable** within-session (moderate-to-good test-retest), so these should have **relatively tight
  floors**. But because they are *absolute* log powers, they are **sensitive to per-channel amplitude
  fidelity and to any global scale error** in the reconstruction — the exact failure mode that made
  ZUNA miss on FAA's absolute-amplitude reconstruction (right-frontal channels reconstructed with a
  channel-specific power bias). Expect single-channel powers to be the more demanding target for a
  method that does not preserve absolute per-channel amplitude.
- **`mu_asym` (asymmetry):** a **difference score**, so it is **noisier** than either component
  (difference scores compound the measurement error of both channels and have lower reliability). Its
  same-day floor will therefore be **comparatively loose / larger**, but it is also correspondingly
  harder to reconstruct stably. Because it is scale-invariant, a purely global amplitude/z-score error
  cancels in `mu_asym` (as confirmed for FAA), so its residual error is driven by the *relative*
  C4-vs-C3 reconstruction bias, not by common-mode scaling.
- **Order-of-magnitude anchor** (do not hard-code): the FAA reference floors on this cohort were
  ≈ 0.21 (mid-frontal) and ≈ 0.30 (lateral) nepers; `mu_asym` is expected to sit in a similar
  **~0.2–0.35 neper** range. This is guidance for sanity-checking, not a threshold — the authoritative
  floor is whatever `aggregate.py` derives from Rest1/Rest2.

Reporting requirement: **emit all three submetrics every run** so `mu_asym` (the headline but noisy
construct) can be cross-read against the two more-reliable single-channel powers.

## 7. Edge cases & robustness requirements

The implementation must be defensive and always return finite `float`s or explicit `float('nan')`:

1. **Missing channels (guard each submetric independently).**
   - `mu_asym` requires **both** C3 and C4 → guard with `C.has(ch_names, 'C3', 'C4')`; if either is
     absent, do not emit `mu_asym` (omit the key, per the `m_faa.py` pattern) or set it to
     `float('nan')`.
   - `mu_c3` requires C3 only; `mu_c4` requires C4 only — guard each with its own
     `C.has(ch_names, 'C3')` / `C.has(ch_names, 'C4')`. It is valid to return, e.g., `mu_c4` and
     `mu_asym`-absent when only C4 survives. The runner skips any submetric key it does not receive,
     so a partial dict is acceptable; missing keys must never crash.
   - Never index `u.index('C3')` without first confirming presence (avoid `ValueError`).
2. **Tiny / zero power → logarithm instability.** `C.bandpower` is non-negative and can be ~0 for a
   flat or near-zero reconstructed channel. `ln(0) = -inf`. Requirement: for `mu_c3` / `mu_c4` add the
   **same `1e-20` epsilon** used inside `C.log_asymmetry` before taking `ln`, so a near-silent channel
   yields a large-magnitude but **finite negative** value, not `-inf`. `mu_asym` already inherits this
   guard from `C.log_asymmetry`. Do not clamp to a physiological range — a large negative log power is
   a legitimate (if extreme) result of a nearly flat channel and should surface as-is, finite.
3. **NaN / non-finite propagation.** If CSD or the PSD produces non-finite values for a needed channel
   (degenerate montage, bad epoch), the corresponding submetric must be returned as `float('nan')`
   rather than a NaN-poisoned number silently written to the CSV. Cast every returned value with
   `float(...)`; do not return numpy scalars or arrays.
4. **CSD prerequisites.** `C.csd` builds a `standard_1005` montage and ignores channels lacking a
   position (`on_missing='ignore'`); it returns channels in the **same order** as `ch_names`, so index
   alignment after CSD is preserved. The contract guarantees `standard_1005` labels, so C3/C4 will have
   valid positions when present; still, treat CSD output defensively (checks in 2–3 cover a failed
   Laplacian).
5. **Small / few epochs.** `C.welch` uses `nperseg = min(1024, n_times)`; a small `n_epochs` yields a
   noisier PSD but remains computable. No special-casing required beyond the finiteness guards above.
6. **Degenerate equality.** If a reconstruction sets C3 == C4 (e.g., common fill), `mu_asym == 0`
   exactly — this is correct behavior, not an error.

Determinism: `compute` must be pure and side-effect-free given `(data, ch_names)`; no randomness, no
global state.
